# Shiwani's Python Practice Repository

A collection of Python learning notes, Jupyter notebooks, small practice programs, and sample data files. The repository covers Python fundamentals, object-oriented programming, NumPy, Pandas, and Matplotlib.

## Contents

### Python fundamentals
- Variables and variable methods
- Type casting
- Built-in and user-defined functions
- Parameters and arguments
- Lambda functions
- Conditional statements (`if`, `elif`, `else`)
- `for` loops
- Lists, sets, tuples, indexing, slicing, and stepping

### Object-oriented programming
- Encapsulation
- Inheritance
- Method overloading and overriding

### Data handling and visualization
- NumPy arrays, dimensions, reshaping, and flattening
- Pandas practice
- Matplotlib introduction and chart examples
- CSV and Excel sample files

### Practice programs
- ATM practice project
- Number guessing game
- Python practice questions and exercises

## Files and formats

- `.ipynb` — Jupyter notebooks containing notes, examples, and exercises
- `.py` — Python source files
- `.csv` — sample tabular data
- `.xlsx` — Excel workbook

Some notebooks are saved as drafts or practice files and may contain incomplete exercises.

## Requirements

- Python 3
- Jupyter Notebook or JupyterLab
- NumPy
- Pandas
- Matplotlib
- A spreadsheet reader such as `openpyxl` may be needed for Excel files

Install the main packages with:

```bash
pip install jupyter numpy pandas matplotlib openpyxl
```

## Getting started

1. Download or extract this repository.
2. Open a terminal in the project folder.
3. (Optional) Create and activate a Python virtual environment.
4. Install the requirements listed above.
5. Start Jupyter:

   ```bash
   jupyter notebook
   ```

6. Open any `.ipynb` notebook and run its cells in order.

You can also run standalone Python files from the terminal, for example:

```bash
python shiwani/shiwani.py
```

## Notes

- The `.ipynb_checkpoints` folders are automatically generated by Jupyter and are not needed for normal use.
- Sample CSV and Excel files are included for practice; check the relevant notebook for how they are used.
- This is a learning/practice collection, not a packaged application. No automated test suite or single project entry point is provided.
